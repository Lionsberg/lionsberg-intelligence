# LIØNSBERG Intelligence System

*The home of the LIØNSBERG Agents — the intelligence layer of the LIØNSBERG System.*

LIØNSBERG serves one Goal — *ØNE · Creator's Intent · Heaven on Earth · for All · forever.* This repository gives each person who plays toward it a sovereign personal agent: one that knows the canon, sees through the Lens, and helps them play the Great Game. The agent adds reach; every decision stays with the person.

## Player+ — the agent you take home

`player-plus/` is **Player+ 3.1.1**, the personal LIØNSBERG Agent. It runs in Claude Code (or any harness that reads a `CLAUDE.md`), on a small local model, or not at all: a notebook plays the whole Game.

On its shelf is the whole library of read.lionsberg.world — The One Book, the Field, the Rosetta Stone, the Player+ Modules, the Superorganism package — and the skills for playing: the roll, the Season Sheet, the Offering, the retrospective, reading the Story aloud, passing the Flame, and the starter kit's skills for keeping a house.

**To begin**, open [`player-plus/START-HERE.md`](player-plus/START-HERE.md), or the library's page *START HERE — Your Player+* at read.lionsberg.world. Make a folder, start Claude Code, paste the first message, answer the questions, read the Story.

## How agents work together

- **IFP — the Inter-Face Protocol** ([Inter-Face-Protocol/ifp](https://github.com/Inter-Face-Protocol/ifp)): how agents speak with each other, and with each other's people.
- **The Agent Improvement Process**: each agent looks back weekly with its person; what is general enough to help every agent is offered upward by pull request. Every agent gets better, and helps every other agent get better.
