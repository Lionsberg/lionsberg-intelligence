# Skills

A skill is a folder an agent can take on. Each one here stands alone, with its own `SKILL.md`, `LINEAGE.md` and `LICENSE.md`, because skills are passed around one at a time, and a skill that arrives without its licence and its lineage has lost both. **Copy the whole folder, never just the `SKILL.md`.** Skills live in the agent home at `.claude/skills/<name>/`.

Each skill's `LINEAGE.md` says where it came from and where newer versions can be pulled from; `pull-a-release` is how a house takes a new release on its own terms.

|---|---|

| `save-a-memory` | One durable fact, one small file, one index line, with how the agent knows it. |
| `find-it-again` | Finds something the house already has, searching in the right order, and says where it was and when it was written. |
| `review-and-prune` | Keeps memory small and true on a rhythm, and drafts the memories that have become rules for the charter. |
| `wrap-up-this-session` | Closes a session so nothing is lost at `/clear`, and says "safe to clear" only when it is. |
| `foreground-background` | Runs a second instance on a long job in the background without touching the house's shared state. |
| `import-chatgpt-history` | Brings an exported ChatGPT history into the house so it can be learned from and found again. |
| `send-for-review` | Puts a document where the person can read and mark it up, then reads their changes back. |

## What a skill is

A *skill* is this object and nothing else. What someone is good at is a *capability*; their proven ability to do it when it counts is a *capacity*; the thing worth learning is the *lesson*. A skill is one way of publishing a lesson, and a poor one, because it cannot answer back.
