# General Needs

*The register of the needs any body will face — a family, a Cell, an assembly, a community, a bioregion, a world — each named once, with what is in hand and what is still to be forged.*

The premise is that the vast majority of what any body encounters is not unique to it. Forming and sealing itself. Aiming together. Agreeing. Deciding without rulers and without gridlock. Meeting well. Staying connected between gatherings. Resourcing, choosing, and delivering the work. Keeping promises visible. Seeing the whole. Learning. Mending. Tending each member. These are general needs, met by general solutions, applied specifically.

It is load-bearing because it is the index by which the three layers stay non-redundant. Each need is named once, here. The timeless HOW lives in [[The LIØNSBERG Pattern Language]]; the WHEN, the choreography, lives as a [[Play]]; the instrument in hand lives in [[The LIØNSBERG Toolkit]]. The register only maps — it never duplicates — and every Play answers a need named in it. It is also the body's honest gap list: where a Pattern, Play, or tool does not yet exist, the register says *to forge*, which makes it the commissioning list for [[The LIØNSBERG Workshop]].

How it is used. Start from the need you actually have, not from the shelf you happen to be standing in front of. Follow it to the tool in hand and use that. If what you need is marked *to forge*, you have found work worth doing, and what you build there is owed back to everyone with the same need — knowledge is a commons. If your need is not on the register at all, that is a [[Proposal]]: add it, so the next body does not have to discover it alone.
