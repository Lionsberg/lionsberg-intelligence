# The Heartbeat

*The same beat in every Cell on Earth: one gathering, one week, everywhere.*

The Heartbeat is [[The Turn]] seen from above. One Cell keeping a weekly gathering is a habit; every Cell keeping one, on the same seven-day rhythm, is a circulatory system. Sheets arrive together. Proposals gather at the same turning. A request made at one table can be answered from another within a week, because every table looks up at the same interval.

It is load-bearing because synchrony is what lets a body without a center act like a body. There is no schedule handed down and no calendar anyone owns: each Cell picks the day it gathers, and that day begins its week. What is shared is the interval, not the hour — one week, four turnings a year, kept by the sun. That is enough for the whole to keep time with itself, and little enough that no table has to ask permission to live its own life.

How it is kept. Gather weekly, the same day if you can. Roll the look-ahead each week so that the beat carries planning and not only reporting. Mark the cards. Tell one story. Put something in the middle. Close in gratitude. Between the weeks, the daily practice keeps a person in rhythm — pause, ground, breathe, remember, realign, recommit — and each month a synthesis; at the turning, the season's breath. A beat missed is not a sin; a beat abandoned is how a Cell quietly ends.
