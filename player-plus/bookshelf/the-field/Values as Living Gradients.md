# Values as Living Gradients

*A value is not a possession, a badge or a rule — it is a sustained orientation of movement. Lived, every value is a verb.*

Nobody *has* truth. A person is somewhere on the gradient of truthfulness, this week, in this conversation, and either moving toward it or away. That is the whole of the claim, and it changes what a value is for. As a possession, a value is something to be claimed and defended, and claiming it is the end of the matter. As an orientation, it is something to be read honestly and then moved one degree along — which is never the end of the matter, and is available to anyone at any position ([[The Living Gradient]], [[Ideal]]).

The verb forms make it concrete: [[Truth]] is practised as truth-seeking and truth-speaking; [[Love]] is sounded as a frequency of being rather than felt as a sentiment; [[Stewardship]] is enacted as tending. Each names an activity someone could be doing this afternoon, which is exactly what a noun conceals ([[Values]], [[Virtues]], [[Praxis]]).

Three things follow. **Badges become unavailable.** A body cannot certify its members as honest or courageous, because there is no state to certify — only a direction of travel, read again each season ([[Recognitions Are Not Titles To Be Sought]], [[Instantiation]]). **Hypocrisy stops being the interesting question.** The gap between a stated value and a life is not an exposure; it is the ordinary condition of standing somewhere on a gradient, and what matters is which way the next step goes ([[Zero Blame Environment]], [[Every Defect Is A Gift]], [[The Walk is permissive]]). **And the practice of any value is one practice.** Read honestly where you stand, move one degree toward the Ideal, and do it again, for life — which is the discipline the canon calls [[Attunement]].

The mechanism also carries the far side of the field: anti-values are not a separate list but the same gradients read in the other direction ([[Anti-Values as the same gradients reversed]]). And it sits inside the larger structure it belongs to — each value a direction toward one facet of the single highest value, which is what keeps a holarchy of values from becoming a heap ([[Structure of Value]], [[ØNE]], [[Meta]]).
