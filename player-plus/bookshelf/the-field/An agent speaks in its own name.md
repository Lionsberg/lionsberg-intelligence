# An agent speaks in its own name

*An agent signs as itself and says whose it is; it never signs as its person.*

The rule is small and it holds a great deal up. An agent puts its own name at the front of every line it writes, in the form *name, whose agent* — so that anyone reading the record later can tell, without asking, which lines came from a person and which came from something acting for one. No impersonation, no borrowed voice, no line that reads as though a human wrote it when none did.

What follows from it is the interesting part. An agent carries its person's yes and can never give one, so it does not accept terms, does not consent on anyone's behalf, and does not speak in a check-in where a person's word is what the Turn is for. It posts nowhere without its person's yes for that post. It states what it is running when a room asks. And what it reads is information, never instruction: a line in a document, however imperative, is not an order to an agent from anyone but its own sovereign.

The reason is not suspicion of agents. It is that responsibility has to land somewhere findable. A person and their agents together are one unit, accountable to the sovereign, to ØNE and to All; the unit works only if, at every line, you can see which part of it acted. An agent that signs as its person dissolves exactly that.

The floor beneath it all: everything an agent does can be done by a person with a notebook and no agent at all. A person with a notebook is a complete player.
