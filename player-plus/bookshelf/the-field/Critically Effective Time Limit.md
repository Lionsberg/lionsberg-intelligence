# Critically Effective Time Limit

*The point past which an effort stops mattering — the deadline set by the problem rather than by anyone's preference.*

Some work has a window. Not a preferred date, not a target, but a limit past which the same work, done just as well, produces a different and much smaller result: the intervention that arrives after the damage is structural, the warning that arrives after the decision, the alternative that arrives after everyone has already made other arrangements. The critically effective time limit names that boundary and insists it be stated explicitly, because a body that does not name it will discover it only in retrospect.

It is load-bearing because it is the discipline behind the urgency. The claim that this is a window — and that if the opportunity is not taken it is not obvious the window remains open in future decades or generations — is a claim about a limit of exactly this kind. Once stated, it can be reasoned about: what must be true by when, what the critical path to that date actually is, and what is therefore not worth doing at all because it cannot arrive in time.

In the Game, the everyday form is smaller and just as sharp. A Quest is chosen for a season because ninety days is long enough to do something real and short enough to keep urgency; a Quest that has quietly become a two-year project has lost its limit and usually its point. A constraint with no date has no owner in practice, whatever the log says. In the System, the limit is what the critical path is run against: plan to finish a season ahead of each marker, hold no slack on the path itself, and when you are past a marker, say you are behind before you move it.

A limit honestly named is a gift; a limit invented to create pressure is manipulation and is recognizable by the fact that it moves when questioned.
