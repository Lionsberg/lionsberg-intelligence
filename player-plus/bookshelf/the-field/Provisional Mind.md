# Provisional Mind

*The first, rough version of a shared mind — a distributed memory that many can write to and read from, standing in until something better is grown.*

The canon's sense is concrete rather than philosophical. A shared mind has to start somewhere, and what it started as is a basic shared distributed memory: a wiki. Plain pages, held in common, edited by many hands — the least impressive possible implementation of a collective intelligence, and a working one ([[The Record]] · [[Knowledge as commons]] · [[MindWeaving]] · [[Mind]]).

The word doing the work is **provisional**. It is not a modest disclaimer; it is a status, and it is the same status everything else here carries. The thing exists, is depended on, and is expected to be replaced by something better — so it may be used fully without anyone confusing it for the destination ([[Current Best Understanding]] · [[Everything Is Current Best Understanding]] · [[Provisional Backbone]] · [[Prototype]] · [[LIØNSBERG Is A Prototype, Not The Eternal Essence]]).

That naming does two things at once. It permits building now with what is at hand rather than waiting for the right instrument ([[Do the Work]] · [[Learning By Doing]] · [[The Floor And The Ceiling Of The Kit]]). And it keeps the successor thinkable — a thing called provisional cannot quietly become permanent by nobody noticing ([[Drift]] · [[Institutional Idolatry]]).

What a shared mind is *for* is the part worth holding onto while the instrument changes. Every mind is finite, and what no single vantage can see becomes visible only when many honest renderings are woven together; the memory is only the medium that makes the weaving possible across time and distance ([[MindWeaving]] · [[Perception]] · [[Sensemaking]] · [[Navigating Towards Truth]] · [[Dialogos]]).

And it is held provisional in a second sense that the canon means everywhere: the *contents* of the shared mind are provisional too. A shared memory that could not be corrected would be worse than none, because it would be believed ([[Weave, don't delete]] · [[The Wiki Reflects the Present]] · [[Second reader]] · [[We Do Not Know]]).
