# Catalytic Resources

*The knowledge, funding, tools, and relationships that unlock a Quest which is otherwise blocked — the input side of the constraint log.*

A Cell with a real Quest and real commitment can still be stopped by one missing thing: money to begin, an expert who has done this before, a tool nobody local owns, or an introduction to the people already working two valleys over. Catalytic Resources is the name for that class of input. The word is chosen carefully — a catalyst is not consumed and is not the reaction; it is what makes a reaction that was already possible actually happen. The Quest is the Cell's; the resource only unblocks it.

Five kinds are named: **financial capital** that lets a thing start and keeps it alive long enough to be judged; **knowledge and expertise**, shared rather than sold, so nobody pays twice for a lesson already learned ([[Knowledge as commons]]); **technology and tools** that make the difficult ordinary; **networks and collaboration**, the introductions that turn parallel efforts into one effort ([[Silos No More]]); and **mentorship and support**, the accompaniment that keeps people going through the part where it stops being exciting ([[Apprenticeship]] · [[Wise Eldership]]).

It earns a name because of where it sits in the work. A Cell's blocked Quest produces an [[Issue]]; the issue names a [[Constraint]]; the constraint names the resource that would relieve it. That is the same logic the delivery disciplines run on — find the constraint, relieve the constraint, find the next one ([[Theory Of Constraints]] · [[Make-Ready Process]]). Catalytic Resources is the vocabulary for the relief side, and it is what makes a body's [[Requests and offers]] more than a noticeboard: a request that names the constraint it would relieve can be answered precisely, and by a stranger.
