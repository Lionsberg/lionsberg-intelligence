# Pattern-Languaging

*The verb: the ongoing work of finding, naming, articulating and retiring the patterns that make up the Language.*

A pattern language is not a book that gets finished. It is a practice, and naming the practice as a verb keeps that visible. To pattern-language is to notice that something which works has a shape; to name the shape; to write it as context, forces and solution so that someone else can use it; to link it to its neighbours; and to let it be corrected by everyone who tries it.

The maintenance has a known rhythm: fill up what is lacking, improve what remains, remove what does not belong. A pattern enters the language when it has been found working in more than one place, matures as it is used, and retires when what it described has stopped being true. Most candidates fail the first test, and should: naming a thing is cheap, and a list of well-formed names with nothing behind them looks like a language while carrying none of the load.

That failure mode is visible now. A large sweep of verb-coinages was generated in one pass — hundreds of names, well-formed, with no card, no use and no inbound link outside their own list. They are a backlog, not a language. What distinguishes real pattern-languaging from its imitation is that a real pattern is written because someone needed it and someone else can now use it.

The naming itself follows the language's own conventions: three shapes are allowed — a noun, a gerund, or a composed phrase — and a name is chosen for what it does to the reader's recognition, not for how it sounds in a list.
