# Continuous Improvement

*The standard is not perfection but a little better every day — and nothing is exempt from being made better by whoever uses it.*

Continuous improvement replaces one standard with another, and the replacement is the whole move. Where the standard is perfection, every miss is a failure, misses get hidden, and the system learns nothing. Where the standard is improvement, every miss is information, misses get surfaced immediately, and the system learns constantly. [[Every Defect Is A Gift]] is the same claim stated from the other end, and it only works because the standard changed first.

The loop behind it is stated as **attend · plan · act · learn · improve**: notice the issue or the variance from plan; investigate the root cause and propose a hypothesis; test it small; assess the result and the gap between expected and actual; then either adopt it as the new standard or revise and run again. The new standard immediately becomes the thing to improve next. It has been argued that this loop — plan, act, learn, improve — is the only truly mandatory element of the System, and the argument is a fair one: a body with the loop will eventually build everything else, and a body without it will decay whatever it was given.

Two things make it real rather than aspirational. **It is written down.** Lessons learned are documented and propagated across every instance of the System, so a solution found once anywhere becomes available everywhere — solve, document, push it up, pull it down, localize, feed back. **A line closes only when its fix sits where the work will meet it**; a lesson recorded somewhere nobody looks has not been learned. Beside those, the ordinary instruments: [[Retrospective]] each week, [[OmniSpection]] each season, and a defect log carrying every miss the day it happens.

The cultural half matters as much. Nothing here is fixed or final; every page, tool, and agreement is open to improvement by whoever uses it; and [[Current Best Understanding]] is the status everything is held at, so improving something is ordinary rather than an accusation.
