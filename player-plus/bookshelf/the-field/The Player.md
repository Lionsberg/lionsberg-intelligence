# The Player

*Everything in the system is a Player — a person, a person with their agents, a [[Cell]], a Cell of Cells, a community, a world — and every Player holds one card of the same shape.*

The word does two jobs. In the Game it names a person who has chosen to play, and an artificial agent is never one. In the Operating System it names the *unit that holds a card*: whatever thing plans, commits, records and reports. A person is a Player; a person and their agents together are a Player+; a Cell is a Player; so is a supercell, a community, a world. Each keeps one record, plays the same moves, and differs only in scale.

This is what lets one pattern run from a kitchen table to a planet without a second system for the upper floors. Because the card shape is the same, [[The plan of the whole]] can be broadcast down as the upper half of every card and a season can be read back up; because the moves are the same, learning to run one Cell well is learning to help run a world. Remove it and the system needs one grammar for people, another for teams, another for institutions — which is the fragmentation it exists to end.

In practice a Player is named on the first card: name, players and roles this season, our home, the Cells beneath us if any. Every object it keeps — an activity, a milestone, a Quest, a commitment — carries [[An address]], its place in the whole, held apart from who it is. A Player commits to another Player, never to a task, and the weight of a chain never rests on one person alone.
