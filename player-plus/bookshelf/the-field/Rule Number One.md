# Rule Number One

*There is only ØNE rule. Everything is ØNE — and from that, the wise right thing can be spiritually discerned, energetically sensed, and logically derived, in any time or place.*

It is called the Meta Rule because it is not one rule among others; it is what every other rule would have to be derived from. And it is not an instruction. It is a statement about what is the case — *everything is [[ØNE]]* — from which instruction follows, rather than a command from which obedience follows.

The reason a body of this kind wants exactly one is practical before it is metaphysical. A list of rules is a list of situations someone anticipated, and reality reliably produces the situation nobody anticipated; worse, two rules eventually conflict, and then something outside both must decide, which means the list was never the authority ([[One (the One Thing)]], [[Structure of Value]]). A single rule does not run out. It has to be interpreted every time, which sounds like weakness and is the whole design: it puts the discernment back in the hands of the one acting, where it belongs ([[Sovereignty]], [[Discernment]]).

Three ways of reading it are named, and they are given as equals rather than as a hierarchy: the wise right thing can be **spiritually discerned**, **energetically sensed**, and **logically derived** ([[Types Of Knowing]], [[Sensing The Field]], [[Wise Right]]). That is a deliberate refusal to make any one faculty the arbiter — the mystic, the sensitive and the reasoner are each given a road, and their agreement is the check. Where they disagree, the disagreement is information ([[Discernment]], [[We Do Not Know]]).

What it forbids is therefore quite specific. If everything is one, then no harm done to any part is done to a stranger, and no gain taken from any part is a real gain ([[All]], [[The All (the reconciliation)]], [[Right Relationship]], [[First, Do No Harm]]). The whole ethic is contained in the ontology, which is why so few rules need be stated to say enough ([[Rule Number 2]], [[The Rules of The Game]]).

And it is the guard against everything else written. A rule that lives above every written thing is also what authorises correcting every written thing ([[Spirit Precedes Pattern]], [[Everything Is Current Best Understanding]], [[Institutional Idolatry]]).
