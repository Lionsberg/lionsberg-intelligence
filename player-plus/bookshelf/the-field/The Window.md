# The Window

*The open interval in which a world can still choose — the span in which the crossing from the old pattern to the new remains possible, before [[Collapse]] closes the way.*

Some things can be done only while a door stands open. A wound can be set before it heals crooked; a seed can be sown before the season turns; a people can change course before the ground beneath them gives way. The Window is that interval at the scale of a civilization — in the older language of design science, the [[Critically Effective Time Limit]], the span within which effective action remains possible at all. It did not open on a schedule and it will not close on one. Its edges are not visible from inside it. What is knowable is that it is open now, that it has been narrowing, and that every season spent feeding the old pattern narrows it further.

Holding this changes how time itself is carried. The Window is **not a deadline**: deadlines are markers we set to manage our own work, and we may move them; this interval is set by reality and cannot be renegotiated, extended, or appealed ([[Temporal markers apart from milestones]]). **Contingency assumes it stays open** — a plan that runs late intends to spend its reserves, but reserves can only be spent inside an open window, so lateness on the [[Critical Path]] is never merely a scheduling problem ([[Float]], [[Honesty about time]]). And it is **read, not calculated**: because [[We Do Not Know]], its width is a continual matter of discernment and watching the signs, season after season ([[OmniSpection]], [[Discernment]]).

From this follows the one posture that is neither denial nor panic: act as if it could close at any hour, and never despair — the same unknowability that could close it early may also hold it open longer than any calculation allows. Urgency, because the interval is real and finite. Peace, because panic feeds the very unravelling that closes it, and because the work goes fastest when it is done in the spirit of the world it is building. This is why the near-term ask is [[The First Three Percent]] and not everyone, and why a body that needs the hour to be worse in order to be right has already been captured by it.
