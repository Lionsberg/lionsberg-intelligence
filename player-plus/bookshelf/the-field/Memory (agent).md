# Memory (agent)

*Notes an agent keeps between conversations; memory advises, the charter binds.*

The model itself keeps nothing about you. Anything that survives a conversation survives because it was written into a file or a setting the agent opens at the start. Those notes are its memory: what it learned about how you work, your promises and their dates, the things you asked it to hold. Some assistants save such notes without being asked, which is worth asking about plainly: *do you save anything about me that I did not ask you to save, and where can I see it?*

It is load-bearing because of a single ordering that is easy to get wrong. Memory may or may not be reread in a given conversation, so it is a strong nudge and never a rule. What must always hold goes in the charter. A correction spoken in passing usually lands in memory if it lands anywhere, which is exactly why yesterday's firm word did not survive to today.

A Player+ keeps memory honest rather than large. Every few weeks read the memories together: merge what overlaps, drop what is stale, promote into the charter what must always hold. Before acting on a memory that names a file, a person, or a claim, check that it is still true; a memory is what was true when it was written. Each note says where it came from — heard from you, with the date, or read, and where — so that a thing you said is never confused with a thing the agent found.

What an agent holds about its person goes nowhere else without their word: not to another agent, not onto a shared page, and not into anything kept for other people to read.
