# Cell Types

*A differentiation of function among Cells in one body — what a Cell has become, not what it contains. Discovered, never decreed.*

Every [[Cell]] carries the whole code and meets the same standards. A Cell Type names what a particular Cell has taken up in service of the larger body: what it does for the whole that no other kind of Cell does in the same way.

The law beneath the types is borrowed from the thing it is named after. In a living body every cell descends from one cell and holds the complete genome; differentiation switches on what a cell *expresses*, never on what it *holds*. A neuron and a liver cell carry the same code and do different work. So here: a [[Guide Cells|Guide Cell]] and a Cell that builds are both Cells first, each still holding [[The Goal]], [[The Golden Seed]], and the way of playing, so that neither needs a centre to live. Because the code is whole in every Cell, a Cell may change type as the body's need changes, and a body that has lost a type can regrow it from any living Cell ([[Self-Sustenance and Self-Replication]], [[Holon]]).

The first types are deliberately few. Guide Cells hold a domain's current best understanding and answer requests in it. The Cells that imagine, design, and build carry a Quest from intention through design to a delivered work — and no name has been forced on them, because the name should arrive with the thing rather than before it. A young Cell usually expresses no type at all: it plays its Quest, and the body learns what it is good for.

The checking lens is living systems rather than organisation charts. Two questions are asked of any proposed type. *Does a living body have this differentiation, and why?* — bodies differentiate for sensing, deciding, remembering, producing, transporting, defending, repairing, and reproducing, and a type with no living analogue is suspect. *Does the type still carry the whole?* — a differentiation that strips a Cell of its completeness is not a type but a wound ([[Living System]], [[Complex Adaptive Living System]]).
