# The Great Game

*A book on the Player+ shelf: a first reading of The Great Game of LIØNSBERG, in eleven short chapters, each standing alone and each pointing at the canon page it translates.*

This is the first of three tiers. Read these chapters to play a first season; read [The One Book](../the-one-book/The%20One%20Book.md) and the rulebook to hold the whole; clone the canon (github.com/Lionsberg/lionsberg-wiki) to hold all of it. **Whose words.** Where the canon has a page, the chapter quotes it and points; where it does not, the chapter says so. The canon's words are CC BY-SA 4.0 (Lionsberg/lionsberg-wiki). *Circle* is the gathering; *Cell* is the unit that plays. A *Player+* is a person with any agents that act for them, or a person with a notebook. Every chapter ends with a line for the notebook, because a person without an agent is a complete player.
