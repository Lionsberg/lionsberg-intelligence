# The Rosetta Stone

*The words at the table, in the languages that reach most of the world — the same 1469 concepts, the same numbers, so that a Cell in one language can find the exact word a Cell in another is using.*

This is a machine-assisted first pass. Proper nouns stay (LIØNSBERG, ØNE, LUV, TEA, Player+); ØNE is never translated; Heaven takes each tradition's nearest word and the page says which and why; the twelve words that carry the Game (Cell, Circle, Quest, Turn, Season, Flame, Offering, Carrier, Home Cell, Supercell, Proposal, Home) take one working name each, chosen once and kept. Every page says at its head that a native reader is wanted before any table plays in that language. If that reader is you, the page's foot note lists the ten words its translator was least sure of: begin there.
